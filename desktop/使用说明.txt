Galgame 推荐系统（第一阶段）— 使用说明
========================================

一、这是什么
  本地窗口输入偏好描述 → DeepSeek 生成 VNDB Filter → 查询 VNDB.org
  → 返回高分匹配作品（名称/评分/简介/官网链接）。
  纯元数据推荐，无爬虫、无下载/资源链接。

二、准备
  1. 安装依赖（在 vn_ai_skill 目录）：
       pip install -r requirements.txt
  2. 编辑 config.py，把 DEEPSEEK_API_KEY 改成你的 Key
     （也可设置环境变量 DEEPSEEK_API_KEY）

三、启动
       cd vn_ai_skill
       python main_gui.py

四、输入格式（强制）
       这是我想要的galgame描述：校园纯爱、日常治愈、无刀、画风清新、高分口碑作品

四-附、搜索模式（界面三选一）
  - 总质量优先：标签强度可低，作品评分必须高（默认约 7.5+）
  - 内容权重优先：核心标签强度 ≥ 2.4；次要 2.0 或 1.6（由模型判断）；评分次之
  - 硬核内容要求：核心标签 ≥ 2.8（优先 3.0）；评分 ≥ 6.2；允许极端情况无结果

四-附2、年份下限
  界面可设发售年份最低限度，低于该年的作品不推荐。
  存档/强制写入 Filter：["released", ">=", "年份"]

四-附3、收藏夹
  结果列表左侧勾选 →「加入收藏夹」
  存档文件：项目根目录 favorites.json
  「打开收藏夹」可查看/删除

四-附4、会话与操作
  - 「开始新一轮搜索」：明确清空会话并重新分析（会确认）
  - 「刷新结果」：沿用上轮条件，尽量避开已看过的游戏
  - 「优化上轮分析」：改/补自然语言，AI 增删标签后重搜
  - 「仅按一个核心标签搜索」：启用后只保留 1 个核心标签检索
  - 双击列表项：查看中文剧情简介与出版社/开发商
  - 摘要用中文展示 AI 搜索标签；每款结果附带权重前4其它标签（中文，不含搜索标签）
  - 简介自动译为中文

五、流程约束
  - 首次运行会自动下载 VNDB 全量标签库（约 3000+，缓存 7 天）
  - 自然语言 → 全库标签检索候选 → DeepSeek 只能从候选里选 gID
  - 非硬核模式：每次查询最多 2 轮 VNDB（无结果可宽松 1 次）
  - 硬核模式：不强制放宽，允许 0 结果
  - 查询结果缓存 1 小时；非法 Filter 会被本地校验拦截

  手动刷新标签库：
       python tag_catalog.py
