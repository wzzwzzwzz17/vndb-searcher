勾选后可收藏。点「查看详情」看中文简介和出版社。双击卡片也可以。

查询作品需要能访问 api.vndb.org。国内网络通常要打开 VPN（梯子）。DeepSeek 一般可直连。标签库已内置在应用里。

三分钟就会用

  1. 描述必须以「这是我想要的galgame描述：」开头。
  2. 选一种找法：总质量看高分；内容权重看标签够不够浓；硬核要求更严，可能没有结果。
  3. 年份用来挡住太老的作品。勾选「只按一个核心标签」时，只拿最关键的那一个标签去搜。
  4. 「刷新结果」会尽量换一批，不重复刚才看过的。「优化上轮分析」用来补充或改掉上一句需求。
  5. 结果里的简介是中文。每部还会列出权重最高的 4 个其它标签（不含这次用来搜索的标签）。
  6. 本应用只查 VNDB 上的作品资料，不提供下载。

关于 VNDB搜索器

制作者：雨里百跳（代号）

注意事项

  • 只查询 VNDB 公开元数据：名称、评分、简介、标签、链接、开发商。没有资源、没有下载。
  • 请遵守 VNDB API 使用条款（非商业、有频率限制）。请勿短时间连续狂点搜索。
  • 成人向标签来自 VNDB 官方分类。请自行遵守所在地法律。
  • DeepSeek Key 存在本机，用于把自然语言变成筛选条件，并翻译简介和标签。
  • 内置约 3000 个官方标签，所以匹配标签本身不需要先连上 VNDB。真正列出作品时仍要访问 VNDB，国内通常需要 VPN。
  • 硬核模式允许找不到作品，不会为了凑结果把条件放得很松。
