关于 VNDB搜索器

制作者：雨里百跳（代号）

注意事项

  • 作品详情里的参考页来自鲲 Galgame、TouchGal、真红小站和 GGBase。GGBase 只按日文找栏目页。这些都只打开作品页或栏目页，不提供压缩包或磁力链接。鲲使用公开接口，不需要 Token。
  • 请遵守 VNDB API 使用条款（非商业、有频率限制）。请勿短时间连续狂点搜索。
  • 成人向标签来自 VNDB 官方分类。请自行遵守所在地法律。
  • DeepSeek Key 存在本机，用于把自然语言变成筛选条件，并翻译简介和标签。
  • 内置约 3000 个官方标签，所以匹配标签本身不需要先连上 VNDB。真正列出作品时仍要访问 VNDB，国内通常需要 VPN。
  • 硬核模式允许找不到作品，不会为了凑结果把条件放得很松。

只用于读取 TouchGal 评分和作品页。保存发生在点「关闭」时。鲲不需要填写。
